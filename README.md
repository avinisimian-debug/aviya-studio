# AVIYA Studio

Premium digital studio website — cinematic, Hebrew RTL, product-company calm.

## Run

```bash
cd studio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- Framer Motion
- Heebo + Instrument Serif

## Structure

Single-page experience: Entrance → Hero → Thesis → Problem/Shift → Principles → Method → Work → Fit → Contact.
