# AVIYA Studio

Premium digital studio website — cinematic, Hebrew RTL.

The Next.js app lives at the **repository root**. The package name is `studio`. There is no `studio/` subdirectory.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4 (`tailwind.config.mjs` is the config the CSS loads)
- Framer Motion (kept for older components; the public pages use CSS motion)
- Heebo for Hebrew, Instrument Serif for the Latin wordmark

## Environment

Copy `.env.example` to `.env.local`.

| Variable | Effect |
| --- | --- |
| `NEXT_PUBLIC_SITE_URL` | Canonical host, sitemap, Open Graph. Set after DNS is live. |
| `NEXT_PUBLIC_GSC_VERIFICATION` | Google Search Console meta tag. Omitted when empty. |
| `NEXT_PUBLIC_GA_ID` | GA4 (`G-…`). Loads only after consent. Off when empty. |
| `NEXT_PUBLIC_PHONE` | Phone CTA. Hidden when empty. |
| `NEXT_PUBLIC_WHATSAPP` | WhatsApp number (`972…` or `05…`). Hidden when empty. |
| `NEXT_PUBLIC_STUDIO_EMAIL` | Public email. Defaults to `studio.aviya1@gmail.com`. |
| `RESEND_API_KEY` | Resend API key. Required together with `LEADS_TO_EMAIL`. |
| `LEADS_TO_EMAIL` | Inbox that receives inquiries. |
| `RESEND_FROM` | Optional from-address. Defaults to Resend’s onboarding sender until a domain is verified. |

### Leads

The contact form posts to a server action (`submitInquiry`).

- Zod validates name, phone **or** email, the requested service, and an optional budget.
- A honeypot field and a per-IP rate limit drop spam.
- If `RESEND_API_KEY` and `LEADS_TO_EMAIL` are both set, the action sends the email through [Resend](https://resend.com).
- If they are not set, the action returns **NOT CONFIGURED**. The page says the inquiry was **not** sent and was **not** stored. Nothing is pretended.

Phone and WhatsApp buttons are separate from the form. They render only when their env vars are set. On small screens they sit in a sticky bar with the inquiry link.

## Google Search Console

1. Deploy the site and set `NEXT_PUBLIC_SITE_URL` to the live `https://` origin (no trailing slash).
2. In [Google Search Console](https://search.google.com/search-console), add a property for that exact origin.
3. Choose the HTML tag method. Copy only the `content` value into `NEXT_PUBLIC_GSC_VERIFICATION`, redeploy, and click verify.
4. Open **Sitemaps** and submit:

```text
https://YOUR-DOMAIN/sitemap.xml
```

5. Use URL inspection on the homepage and request indexing. New sites are not ranked first just because a sitemap exists.

`/sitemap.xml` and `/robots.txt` are generated by the App Router. `robots.txt` points at the sitemap and blocks `/leads`, `/api/`, `/google`, and `/promote`.

Each public page has a Hebrew title and description, a canonical URL, and Open Graph / Twitter images from `src/app/opengraph-image.tsx` and `src/app/twitter-image.tsx`. Schema.org covers Organization + ProfessionalService, WebSite, BreadcrumbList, Service, and FAQPage where that content is visible.
